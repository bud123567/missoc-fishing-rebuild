# Miss Ocean City — website rebuild

A rebuild of missocfishing.com as a single, fast, mobile-first page.

All business information, pricing, trip times, copy and photography are taken
from the existing site. Nothing here is invented.

- **Booking** goes to the live FareHarbor account (`missocfishing`):
  - Bay fishing trips — item `27299`
  - 2 hour private cruise — item `27300`
  - 3 hour private cruise — item `27647`
- **Photography** was pulled from the current site's own media library.
- No build step, no framework. Open `index.html`.

## Known content questions for the owner

- The current site gives the boat length as **52 feet** on the home page and
  **50 feet** on the private charters page. This build uses 52.
- The parking page gives the Shark's address as **12944** Sunset Ave, while the
  FAQ and footer give **12924** Sunset Ave. This build uses 12924 throughout,
  matching the footer and the GPS instruction.
